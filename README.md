# Hannah's Personal Website

A personal portfolio website built for a class assignment and deployed with **GitHub Pages**.

🔗 **Live site:** [https://aventurtyme.github.io](https://aventurtyme.github.io)

## About

A single-page portfolio with a black-and-white, monospace, developer-inspired aesthetic, featuring subtle ASCII art decoration. It presents my background, experience, education, projects, and skills.

## Sections

- **Hero** — name and short intro
- **Experience & Education** — NTU and Singtel PEAK
- **Projects** — FinSight, F1 Pit Stop Analyser, SME Insurance Analytics
- **Skills** — languages, frameworks, data, and tools
- **Contact** — GitHub, LinkedIn, email

## Tech Stack

- HTML5
- CSS3 (no frameworks)
- Vanilla JavaScript
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/) via Google Fonts

No build tools, backend, or dependencies — plain static files, deployed directly through GitHub Pages.

## Project Structure

```text
.
├── index.html

└── README.md
```

## Running Locally

Clone the repo and open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

This site is deployed via GitHub Pages from the `main` branch of this repository (`aventurtyme.github.io`).
